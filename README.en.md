# 无空 PLC / WinCC Portfolio

This repository contains the bilingual portfolio website built with Quartz. The engineering projects were created progressively from blank projects by the author. The site provides a document explorer, search, sidebar backlinks, a local relationship graph and downloadable workbooks.

[English content](content/en/index.md) · [Chinese content](content/index.md) · [Sources and responsibilities](content/en/sources.md)

For local preview, install Node.js 22+ and npm 10.9.2+, then run `npm ci` and `npx quartz build --serve`.

For publishing, push the source to a public GitHub repository and select GitHub Actions under Settings → Pages. The included publishing workflow derives the URL from the target repository.

The Quartz engine retains its upstream MIT license. Portfolio and third-party content are attributed separately in the source notes.
